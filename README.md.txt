# Infinity.ai

An AI-powered chatbot web application built using HTML, CSS, and JavaScript with Gemini API integration.

## Features
- AI Chatbot
- Voice Interaction
- Markdown Rendering
- Syntax Highlighting
- Dark/Light Theme
- Chat Storage
- Responsive UI

## Tech Stack
- HTML
- CSS
- JavaScript
- Gemini API

## Installation

1. Clone repository
2. Open project folder
3. Add your Gemini API key
4. Run `index.html`
